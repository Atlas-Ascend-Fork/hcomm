# 数据库选型导航

先完成[主指南手动构建与安装](../../README.md#31-手动构建安装)，再浏览[当前随源码提供的后端目录](./)。以该目录中实际存在的一级子目录为准；每个子目录应提供自己的 README.md。

 **📌 提示：**  HCCL_VM_STORAGE_CONFIG 环境变量负责显式声明数据库及其配置，未设置时默认使用 sqlite 数据库；需要指定数据库及配置时，按对应模块 README 完成 HCCL_VM_STORAGE_CONFIG 配置，再回到主流程。

公共三方依赖由根 third_party 维护；模块专属依赖由各模块目录内的 third_party 自管。
